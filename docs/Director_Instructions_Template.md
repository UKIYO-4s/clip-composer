## Phase 1: 基盤構築の指示例

### 【タスク1-1】プロジェクト初期化

```
【タスク1-1】Electronプロジェクト初期化
担当: コーダー1
優先度: 高
依存タスク: なし

目的:
- Electron + Reactの開発環境を構築する
- 基本フォルダ構造を作成する

具体的な作業内容:
1. プロジェクトフォルダ作成
   ```bash
   mkdir shortvideo-generator
   cd shortvideo-generator
   ```

2. package.json初期化
   ```bash
   npm init -y
   ```

3. 必要なパッケージインストール
   ```bash
   npm install electron@28 react@18 react-dom@18
   npm install -D @vitejs/plugin-react vite electron-builder
   npm install tailwindcss@3 react-redux@8 @reduxjs/toolkit
   npm install react-dnd react-dnd-html5-backend
   ```

4. フォルダ構造作成
   - frontend/
   - frontend/src/
   - frontend/public/
   - backend/
   - assets/
   - docs/

5. 基本ファイル作成
   - frontend/src/main.js (Electronメインプロセス)
   - frontend/src/preload.js
   - frontend/src/renderer/App.jsx
   - frontend/src/renderer/index.jsx

期待成果:
- package.jsonが存在する
- フォルダ構造が完成している
- npm installが成功する
- Hello Worldが表示される（npm startで起動）

確認方法:
1. `npm start`を実行
2. Electronウィンドウが開く
3. "Hello World"が表示される

見積もり時間: 1時間

完了したら、成果物のスクリーンショットと共に報告してください。
```

### 【タスク1-2】Pythonバックエンド初期化（並列タスク）

```
【タスク1-2】Pythonバックエンド環境構築
担当: サブエージェント（並列作業）
優先度: 高
依存タスク: なし

目的:
- Python動画処理環境を構築する
- 必要なライブラリをインストールする

具体的な作業内容:
1. backend/フォルダで仮想環境作成
   ```bash
   cd backend
   python3 -m venv venv
   source venv/bin/activate  # Mac
   ```

   ```
   moviepy==1.0.3
   pandas==2.1.0
   opencv-python==4.8.0
   Pillow==10.0.0
   numpy==1.24.0
   ```

3. ライブラリインストール
   ```bash
   pip install -r requirements.txt
   ```

4. FFmpegインストール確認
   ```bash
   ffmpeg -version
   ```
   ※ なければ `brew install ffmpeg`

5. 基本モジュール作成
   - backend/main.py
   - backend/modules/video_processor.py
   - backend/modules/__init__.py
   - backend/utils/__init__.py

6. 簡単なテストスクリプト作成
   - 動画読み込み → 1秒カット → 保存

期待成果:
- 仮想環境が動作する
- すべてのライブラリがインストール済み
- テストスクリプトが動く

確認方法:
1. `python backend/main.py --test`を実行
2. test_output.mp4が生成される
3. エラーが出ない

見積もり時間: 1.5時間

完了したら、`pip list`の出力と共に報告してください。
```

## Phase 2: タイムラインUI開発の指示例

### 【タスク2-1】タイムライン基本レイアウト

```
【タスク2-1】タイムライン基本レイアウト実装
担当: コーダー1
優先度: 高
依存タスク: タスク1-3完了後

目的:
- タイムラインの骨組みを作る
- レイヤーとタイムコードを表示する

具体的な作業内容:
1. frontend/src/renderer/components/Timeline/作成

2. Timeline.jsx作成
   - タイムコード表示領域
   - レイヤー表示領域（V2, V1, S2, S1）
   - 横スクロール可能

3. 各レイヤーをコンポーネント化
   - Layer.jsx作成
   - props: { layerId, layerName, clips }

4. Tailwindでスタイリング
   - ダークテーマ
   - グリッドライン表示
   - 再生ヘッド（赤い縦線）

5. Redux state設計
   - timelineSlice.js作成
   - 初期state:
     ```javascript
     {
       layers: {
         V2: { clips: [] },
         V1: { clips: [] },
         S2: { clips: [] },
         S1: { clips: [] }
       },
       currentFrame: 0,
       totalFrames: 900
     }
     ```

期待成果:
- タイムラインが表示される
- 4つのレイヤーが見える
- タイムコード "00:00:00:00" が表示される
- 横スクロール可能

確認方法:
1. npm startで起動
2. タイムライン領域が表示される
3. V2, V1, S2, S1のラベルが見える

見積もり時間: 3時間

実装中に不明点があればすぐに報告してください。
PMへの確認が必要な設計判断は私（ディレクター）に報告してください。
```

【タスク2-2】クリップ表示コンポーネント実装
担当: サブエージェント（並列作業）
優先度: 高

   props:
   ```javascript
   {
     clip: {
       clip_id: string,
       type: 'random_layer' | 'video' | 'text' | ...,
       start_frame: number,
       duration_frames: number
     },
     fps: number,
     pixelsPerFrame: number
   }
   ```

2. クリップタイプごとの色分け
   - random_layer: #4ec9b0 (緑)
   - video: #007acc (青)
   - text: #dcdcaa (黄)
   - variable_text: #ce9178 (オレンジ)
   - adjustment: #c586c0 (紫)
   - bgm/se: #569cd6 (水色)

3. クリップ内に情報表示
   - タイプ名
   - 長さ（秒数）

4. ホバー時のハイライト

期待成果:
- Clipコンポーネントが動く
- 色分けが正しい
- ホバーでハイライトされる

確認方法:
1. Storybookまたはテストデータで確認
2. 各タイプのクリップを表示
3. 色が仕様通りか確認

見積もり時間: 2時間
```

## 🔧 並列作業の判断基準

以下の条件を満たす場合、サブエージェントに並列作業を指示してください：

### 並列可能なケース
✅ フロントエンドとバックエンドの独立した機能
✅ 異なるコンポーネントの実装
✅ テストとドキュメント作成
✅ デザインとロジック実装

### 並列不可のケース
❌ 同じファイルを編集する作業
❌ 依存関係が強いタスク
❌ APIインターフェースが未確定

## 🚨 緊急時の対応

### 実装中にブロックされた場合

```
ブロッカー報告テンプレート:

タスクID: X-Y
ブロックされている作業: 具体的な内容
原因: わからない部分・エラー内容
試したこと:
1. 試した解決策1
2. 試した解決策2

PM確認が必要か: はい/いいえ
緊急度: 高/中/低
```

### PMへのエスカレーション基準

以下の場合、すぐにPM Shoeiに確認：
- 仕様の解釈が不明確
- 技術的に実現困難
- セキュリティやパフォーマンスに影響
- スケジュールに大きな影響

## 🎓 ディレクターの心得

1. **明確な指示**
   - 曖昧な指示は出さない
   - 必ず期待成果を明示
   - 確認方法を具体的に

2. **並列作業の活用**
   - 独立したタスクは積極的に並列化
   - 依存関係を明確に

3. **進捗管理**
   - 毎日の進捗確認
   - ブロッカーの早期発見
   - PM報告は定期的に

4. **品質管理**
   - コードレビューの実施
   - テストの徹底
   - ドキュメント整備

5. **チーム連携**
   - コーダー ↔ デザイナー間の調整
   - 技術的な相談はデザイナーにも共有
