#### レビューチェックリスト

```markdown
### React コンポーネントレビュー

- [ ] コンポーネント名はPascalCase
- [ ] propsの型定義あり（PropTypes/TypeScript）
- [ ] 不要な再レンダリングがない（React.memo使用）
- [ ] useEffectの依存配列が正しい
- [ ] エラーバウンダリ設置（必要に応じて）
- [ ] Tailwindクラス使用（インラインスタイルNG）
- [ ] アクセシビリティ配慮
  - [ ] ボタンにaria-label
  - [ ] フォーカス可能
  - [ ] キーボード操作可能

### Pythonコードレビュー

- [ ] 関数名はsnake_case
- [ ] docstring完備
- [ ] 型ヒントあり（可能な限り）
- [ ] エラーハンドリング適切
- [ ] メモリリーク対策（動画処理後のclose）
- [ ] パフォーマンス考慮

### デザインレビュー

- [ ] カラーシステム準拠
- [ ] スペーシング一貫性（8pxグリッド）
- [ ] ホバー状態実装
- [ ] アクティブ状態実装
- [ ] 無効状態実装
- [ ] ローディング状態実装（該当時）
```

#### レビューコメントの書き方

**✅ Good**
```
💡 提案: この部分、useMemoで最適化できそうです。
clips配列が大きくなるとレンダリングコストが高くなる可能性があります。

const sortedClips = useMemo(
  () => clips.sort((a, b) => a.start_frame - b.start_frame),
  [clips]
);
```

**✅ Good**
```
⚠️ 懸念: ここでAPI呼び出しをしていますが、エラーハンドリングがありません。
ネットワークエラー時にアプリがクラッシュする可能性があります。

try-catchでの対応をお願いします。
```

**❌ Bad**
```
これダメです。直してください。
（具体性がない、理由がない）
```

**❌ Bad**
```
仕様と違います。
（どう違うか不明確）
```

## 🔍 アクセシビリティガイドライン

### キーボード操作

```
【必須対応】
Tab: 次の要素へフォーカス移動
Shift+Tab: 前の要素へフォーカス移動
Enter/Space: ボタン・チェックボックスの操作
Escape: ダイアログを閉じる

【タイムライン操作】
Space: 再生/停止
C: カット
Delete: 削除
Cmd+Z: 元に戻す
Cmd+Shift+Z: やり直し
```

### フォーカス表示

```css
/* すべてのインタラクティブ要素にフォーカスリング */
*:focus {
  outline: 2px solid #007acc;
  outline-offset: 2px;
}

/* ボタンのフォーカス */
button:focus {
  box-shadow: 0 0 0 3px rgba(0, 122, 204, 0.4);
}
```

### カラーコントラスト

```
【WCAG AA基準準拠】
- テキスト（14px以上）: 4.5:1以上
- 大きなテキスト（18px以上）: 3:1以上
- UI要素: 3:1以上

チェックツール: https://webaim.org/resources/contrastchecker/
```

### スクリーンリーダー対応

```jsx
// ✅ Good
<button aria-label="タイムラインにクリップを追加">
  <PlusIcon />
</button>

<div role="slider" 
     aria-valuemin="0" 
     aria-valuemax="100" 
     aria-valuenow={volume}>
  {/* ボリュームスライダー */}
</div>

// ❌ Bad
<button>
  <PlusIcon />  {/* テキストがない */}
</button>
```
